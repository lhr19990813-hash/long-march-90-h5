# 向着胜利，再出发

纪念中国工农红军长征胜利90周年主题实践 H5，共12页，包含时间轴、路线节点、数字动画、精神解码、天津军人风采、红色家风、津门学者故事、4组党员心声材料卡和青年行动卡。

## 后续填写4名采访对象

1. 将获得授权的照片放入 `assets/interviews/`。
2. 在 `interviews.js` 中填写4个对象的 `photo`、`name`、`identity`、`keyword`、`quote` 和 `meta`。
3. 直接引语须经本人核对，照片须确认互联网公开授权。

也可将采访材料发回，由我继续更新。

## GitHub Pages

仓库使用 `.github/workflows/deploy-pages.yml` 自动部署。首次发布时，在仓库 `Settings → Pages → Build and deployment → Source` 中选择 `GitHub Actions`。
